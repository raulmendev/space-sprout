# Jardín Comunal

A cozy pixel-art space habitat shared by an astronaut and their family on Earth (NASA Space Apps Challenge POC).

| Folder | What |
|---|---|
| [`web-app/`](web-app/) | Angular + Phaser web client. See its README to run it. |
| [`api/`](api/) | NestJS + TypeORM backend on Neon Postgres. See its README to run it. |
| [`shared/`](shared/) | `@garden/shared`: domain types and pure game rules, used by both the web app and the API. |
